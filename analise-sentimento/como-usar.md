# Projeto IA com Transformers

Este projeto demonstra uma análise de sentimentos usando o modelo BERT da Hugging Face.

## Como usar

1. Crie e ative o ambiente virtual:
    - `python -m venv venv`
    - `source venv/bin/activate` (Linux/macOS)
    - `.env\Scripts\Activate` (Windows)

2. Instale as dependências:
    ```bash
    pip install -r requirements.txt
    ```

3. Abra e execute o notebook `analise_sentimento.ipynb`.

4. Veja o DataFrame com sentimento e confiança de cada texto.

# Google BigQuery

Conexão com o BigQuery por conta de serviço, consulta SQL e conversão do
resultado para DataFrame.

*BigQuery connection through a service account, an SQL query and conversion of the
result to a DataFrame.*

A chave fica fora do repositório: defina `GOOGLE_APPLICATION_CREDENTIALS` com o
caminho do JSON e troque `seu-projeto.seu_dataset.sua_tabela` pela sua tabela.

*The key stays outside the repo: point `GOOGLE_APPLICATION_CREDENTIALS` to the JSON
file and replace `seu-projeto.seu_dataset.sua_tabela` with your table.*

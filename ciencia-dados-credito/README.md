# Ciência de dados aplicada a crédito

Guia de estudo dos temas centrais de ciência de dados numa cooperativa
financeira. Cada tópico traz descrição curta, um caso de cooperativa e código
em Python (pandas, scikit-learn) ou SQL. Os temas são:
- modelos de score (credit, behavior, collection) e de propensão;
- preparação de dados e WoE/IV;
- métricas (KS, Gini, ROC/AUC, PSI, matriz de confusão);
- pontos de corte e faixas de risco;
- vintage e MOB;
- segmentação;
- Champion-Challenger e estudos de impacto;
- monitoramento de drift e governança de modelos.

Veja [guia.md](guia.md). São mais de 50 códigos numerados e comentados, todos
com dados fictícios gerados no próprio guia. Os de Python rodam em sequência.

*Study guide on core data science topics for a credit cooperative: credit,
behavior and collection scores, propensity models, data preparation and
WoE/IV, KS/Gini/ROC/PSI metrics, cut-offs and risk grades, vintage analysis,
segmentation, champion-challenger and impact studies, drift monitoring and
model governance. Each topic has a short description, a cooperative use case
and runnable Python or SQL on synthetic data. See [guia.md](guia.md)
(Portuguese).*
